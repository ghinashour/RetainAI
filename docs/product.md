# Product direction

## Phase 1 status

The current repository establishes only the technical foundation. It does not yet implement a customer retention product workflow.

## Product focus

The intended product is a retention intelligence platform that helps companies:

- identify risk
- explain why the risk exists
- recommend a human action
- track interventions
- measure outcomes

## Current foundation design

The core product architecture is still:

Data Sources
→ Ingestion
→ Validation
→ Normalization
→ Canonical Customer/Event Model
→ Feature Engineering
→ ML/Health Engine
→ Risk Explanation
→ Recommendation
→ Human Decision
→ Intervention
→ Outcome
→ ROI Analytics

## Not implemented yet

- customer onboarding flow
- CSV ingestion
- churn ML
- recommendations engine
- intervention management
- outcome analytics
- AI assistant
